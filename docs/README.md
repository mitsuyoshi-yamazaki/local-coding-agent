# 文書の案内

このリポジトリでは、ローカル LLM（自分の機械で動かす大規模言語モデル）を使い、Claude Code のようなコーディングエージェントの主要な機能を、1つずつ自分で実装する。目的は、作ることで仕組みを理解することである。

ここにある文書は、**コーディングエージェントの仕組みを知らないソフトウェアエンジニア**が読むことを想定して書いている。LLM の API を呼んだことがなくても読めるようにする。

## 読む順

| 順 | 文書 | 何が分かるか |
|---|---|---|
| 1 | [コーディングエージェントの仕組み](how-coding-agents-work.md) | LLM が何をするもので、エージェントがどう動くか。どの部分をモデルが担い、どの部分を周りのプログラムが担うか |
| 2 | [作る機能](features.md) | このリポジトリで作る機能の一覧と、それぞれの機能が何をするか。作ると何が分かるか |
| 3 | 使う技術 | このリポジトリが使う技術の仕組み |
| | ・[Ollama](technologies/ollama.md) | 手元の機械で LLM を動かし、HTTP で呼べるようにする実行環境 |

使う技術と作る機能の文書は、使い始めるとき・作るときに足していく。

## 書き方の約束

- 記述には出典（公式の文書・リポジトリ）を付ける。確かめた日を書く
- このリポジトリで実測したことは「実測」と書く
