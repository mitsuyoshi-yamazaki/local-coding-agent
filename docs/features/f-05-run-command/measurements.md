- **失敗の出力を読んで直した**: duration は、pytest の `AssertionError`（期待した値と実際の値）から2か所を直した。words は、時間切れの結果から無限ループと見て、試しのコマンドで1つの入力でも止まらないことを確かめてから直した
- **答えの説明は、直しより弱い**: どちらの課題でも、直しは正しかったが、答えの説明に誤りか混乱があった。通ったかを決めたのは、テストの終了コードだった
- **道具の `timeout` の入力を使わなかった**: `run_command` を11回呼び（拒まれたものを含む）、`timeout` を渡した呼び出しは0だった。時間を限ろうとした1回は、シェルの `timeout` を使った
- **テストの走らせ方**: README を読んだのは4回のうち2回（words・Ctrl-C）。読まなかった2回は、pytest（duration）と `python`（拒む）を選んだ

- **時間切れの重さ**: words では、時間切れの2回（240 秒）が「道具」の和のほとんどだった。2回目は、1回目と同じ形（時間を限らない）で止まらないものを走らせた
