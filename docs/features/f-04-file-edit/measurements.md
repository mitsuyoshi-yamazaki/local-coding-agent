| 項目 | 値 |
|---|---|

| モデル | `qwen3.5:9b`（Ollama） |

試している間に、推論の文の扱いを2度変えた（今の扱いは [推論の文](implementation.md#推論の文)）。走行ごとに、どの版のコードで走らせたかを書く。

| 版 | 推論の文 |
|---|---|
| A（`14214a7`） | 読まずに捨てる（F-03 と同じ） |
| B（`17acca3`） | 走行の記録に残す。次の要求には戻さない |
| C（`b0cde40` 以後） | 走行の記録に残し、モデルの発言の一部として次の要求で戻す |

時間の単位は秒。「入力」「出力」はトークン数。「入力の処理」は Ollama が最後の行で返した値（`prompt_eval_duration`）、「最初の文字まで」「全体」は手元（`measured`）で測った値である。「推論」は推論の文の字数（応答の件の `thinking`）。「最初の文字まで」は推論の文を数えないので、道具を呼ぶだけの応答では「全体」とほぼ同じになる。人が問いに答えるまでの時間は、どの数値にも入らない。「判定」は `tasks/f-04-file-edit/README.md` の判定のコマンド（`unittest` の終了コード）である。

## 送り直して比べた結果

走行の要求の1つを取り出し（`stream` を `false` にした）、持ち主が同じ要求を手元の Ollama に何回か送って、応答を数えた。エージェントは通さず、道具も実行しない。
